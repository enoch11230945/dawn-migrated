Contact: `info@solarclabs.com`

## Starting scope

1. one storefront/theme implementation or migration scope using capabilities present in this repository;
2. buyer-supplied brand/catalogue content or controlled demo content;
3. one agreed primary customer journey such as home → product → cart, where supported;
4. one responsive browser handoff;
5. one implementation note listing integrations and production controls still required.

Custom payment/order backends, Shopify/app-store fees, third-party theme/app licences, large catalogue migration, ERP/fulfilment integration, tax configuration, identity, subscriptions, analytics or ongoing managed commerce are separate scope.

## Acceptance

The starting engagement is complete when the agreed storefront pages/journey render for the buyer's controlled content in the agreed environment and the handoff clearly identifies which commerce integrations are real versus mocked, incomplete or still buyer-configured.

Real-money launch requires separate verification of the exact payment/order/webhook/refund/tax/privacy/security/operations path used by that deployment. No revenue, conversion, uptime or platform-approval outcome is guaranteed.
